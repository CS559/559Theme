{{- /* mathvariant bold fix (Path B). Input: dict "html" . Returns the same MathML with each styled element rewritten to real Unicode Mathematical-Alphanumeric glyphs, so bold/script/etc. render correctly in Chromium (which ignores the `mathvariant` attribute KaTeX emits). Full rationale, evidence, and the failure-mode analysis that makes this safe: docs/math-bold-research/README.md. Mapping table: data/mathvariants.yaml (generated by docs/math-bold-research/gen_mathvariants.py). How it works: - Match every content (content is `<`-free -- these elements hold only text; the TeX echo in carries no mathvariant so it is untouched). - For variant V with a mapping (bold, bold-italic, script, fraktur, double-struck, sans-serif, monospace, ...): map EACH character of content (handles multi-char 123 and ) and drop the attribute. Characters with a glyph become real bold Unicode (best quality); any char without one (e.g. the '.' in a bold "12.5") is kept literal, so bold digits still get real glyphs and only the separator stays plain weight. - `normal` has no entry -> left as-is (MathML Core honors mathvariant=normal), as is any variant not in the table (future KaTeX variants degrade safely). - Pseudo-bold fallback (class="mv-pseudobold", styled in _559.scss) is used only for a *total miss*: a variant we handle where not one character mapped (essentially unreachable with the generated table -- it's the documented safety net for mapping gaps). Content containing '&' (an entity) is skipped entirely; bold operators don't occur in practice (see the research doc). */ -}} {{- partialCached "math/variant-canary.html" "canary" -}} {{- $out := .html -}} {{- $data := hugo.Data.mathvariants -}} {{- $re := `<(mi|mn|mo|mtext)([^>]*?)\s*mathvariant="([^"]+)"([^>]*)>([^<]*)` -}} {{- range $m := findRESubmatch $re $out -}} {{- $whole := index $m 0 -}} {{- $tag := index $m 1 -}} {{- $pre := index $m 2 -}} {{- $variant := index $m 3 -}} {{- $post := index $m 4 -}} {{- $content := index $m 5 -}} {{- $vmap := index $data $variant -}} {{- /* Only act on variants we have a mapping for and entity-free content. */ -}} {{- if and $vmap (not (strings.Contains $content "&")) -}} {{- $glyphs := slice -}} {{- $mappedany := false -}} {{- range $ch := split $content "" -}} {{- $g := index $vmap $ch -}} {{- if $g -}} {{- $glyphs = $glyphs | append $g -}}{{- $mappedany = true -}} {{- else -}} {{- $glyphs = $glyphs | append $ch -}} {{- end -}} {{- end -}} {{- $attrs := printf "%s%s" $pre $post -}} {{- if $mappedany -}} {{- /* at least one glyph substituted: drop the attribute */ -}} {{- $new := printf "<%s%s>%s" $tag $attrs (delimit $glyphs "") $tag -}} {{- $out = replace $out $whole $new -}} {{- else -}} {{- /* total miss: strip attribute, mark for pseudo-bold CSS */ -}} {{- $new := printf "<%s%s class=\"mv-pseudobold\">%s" $tag $attrs $content $tag -}} {{- $out = replace $out $whole $new -}} {{- end -}} {{- end -}} {{- end -}} {{- return safeHTML $out -}}
